# מזרק - הורדות

כאן מפורסמות גרסאות התוכנה "מזרק" (משיכת תנועות מהבנקים וחברות האשראי לתקציב).

**להורדה:** [הגרסה האחרונה](../../releases/latest) ← הקובץ `mizrak.exe`.

התוכנה מתעדכנת מכאן אוטומטית (כפתור "בדיקת עדכונים").

הקוד של התוכנה אינו מפורסם. הוא מבוסס על [כספיון](https://github.com/brafdlog/caspion) (רישיון MIT).
